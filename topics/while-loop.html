The while Loop

Repeat a block for as long as a condition holds — colon and indentation instead of braces, and the multiplication table exercise that ties it together.

Overview

This topic covers the while loop in Python — one of Python's two main looping constructs (the other being for). The while loop repeats a block of code as long as a given condition remains True. The notes also touch on how while looks in C-style languages vs. Python, and briefly mention do-while (which Python does not have natively).

Key Concepts

  • A while loop keeps executing its body while the condition evaluates to True.
  • Python does not use curly braces {} for blocks — it uses a colon : and indentation instead.
  • Loop variables must be initialized before the loop and updated inside the loop, otherwise you get an infinite loop.
  • The classic use-case shown: multiplication table generator.

Detailed Explanation

1. while Syntax — C-style vs Python

The instructor compares the general/C-style while syntax with Python's syntax to highlight the difference:

C-style (curly braces):

while(condition){
    code
}

Python-style (colon + indentation):

while condition:
    code
💡 Tip: In Python, indentation is not just for readability — it defines the block of code that belongs to the loop. Incorrect indentation will cause errors or unexpected behavior.

2. Basic Loop Structure (Anatomy)

A while loop generally needs 3 parts:

  1. Initialization – set up a counter/loop variable before the loop starts (e.g., i = 1)
  2. Condition – checked before every iteration (e.g., i < 11)
  3. Update/Increment – changes the loop variable inside the loop body so the condition eventually becomes False (e.g., i += 1)

If you forget the update step, the condition never becomes False → infinite loop.

Example 1 — Simple Multiplication Table

number = int(input("Enter the number"))

i = 1

while i < 11:
    print(number * i)
    i += 1

Explanation of the code:

  • int(input("Enter the number")) — takes user input (as a string) and converts it to an integer, storing it in number.
  • i = 1 — initializes the counter used to track which multiple we're on.
  • while i < 11: — loop runs 10 times (while i is 1 through 10).
  • print(number * i) — prints the product of number and the current counter i.
  • i += 1 — increments i by 1 each iteration so the loop eventually stops.

Important Points:

  • The loop prints only the result of the multiplication (not the full equation).
  • The condition i < 11 combined with starting i at 1 gives exactly 10 iterations (1 through 10).

Example 2 — Multiplication Table with Full Equation Format

number = int(input("Enter the number"))

i = 1

while i < 11:
    print(number, "*", i, "=", number * i)
    i += 1

Explanation of the code:

  • Same loop structure as Example 1, but instead of printing just the answer, it prints the full equation using multiple comma-separated arguments to print().
  • print(number, "*", i, "=", number * i) — Python's print() function automatically adds spaces between comma-separated arguments, which is why the output looks like a clean equation.

Important Points:

  • Using multiple comma-separated values inside print() is a simple way to format readable output without needing f-strings or .format().
  • This is a very common beginner pattern for generating multiplication tables — good to remember as a template for similar looping problems.

Things to Remember

  • ✅ Python while loop syntax: while condition: followed by an indented block (no parentheses or braces required, though parentheses around the condition are optional/allowed).
  • ✅ Always initialize the loop variable before the loop and update it inside the loop.
  • ✅ while i < 11 with i starting at 1 → loop runs for i = 1 to i = 10 (10 times total).
  • ✅ print() with comma-separated arguments auto-inserts spaces — handy for quick formatted output.
  • ✅ Python has no native do-while loop (this only appeared as a labeled comparison point, not an actual implementation).
  • ✅ int(input(...)) is the standard pattern to read a number from the user in Python.

Quick Revision

A while loop in Python repeats a block while a condition is True, using a colon and indentation instead of curly braces (unlike C-style languages). Every while loop needs an initialized variable, a condition, and an update step inside the loop — skip the update and you get an infinite loop. The example used throughout is a multiplication table generator: take a number as input, loop i from 1 to 10, and print either number * i or the full equation number * i = result. This is a classic beginner exercise for practicing loop initialization, condition-checking, and incrementing.
