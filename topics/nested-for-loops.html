Nested For Loops — Star Pattern Printing

A loop inside a loop, traced step by step with Python Tutor — outer loop controls rows, inner loop controls stars per row.

Overview

This topic covers nested for loops in Python, using the classic example of printing a right-angled triangle made of stars (*). It combines two learning tools:

  1. Python Tutor (pythontutor.com) — used to visualize, step-by-step, how the outer and inner loop variables change and how output is built line by line.
  2. Jupyter Notebook — used to run the actual code and make it dynamic by accepting the number of rows from user input.

The goal is to understand how a nested loop executes internally (which is often the confusing part), not just what code to write.

Key Concepts

  • A nested loop is a loop inside another loop (an inner loop running completely for every single iteration of the outer loop).
  • The outer loop (i) controls the number of rows.
  • The inner loop (j) controls how many stars are printed in each row.
  • print("*", end=" ") prints a star without moving to a new line (keeps printing on the same line, separated by a space).
  • print("") after the inner loop finishes prints an empty string, which just moves the cursor to the next line — this is what creates the new row.
  • The number of stars in row i equals i (row 1 → 1 star, row 2 → 2 stars, etc.), because the inner loop runs range(0, i).

The Core Code

for i in range(1, 6):
    for j in range(0, i):
        print("*", end=" ")
    print("")

Line-by-line explanation

LineWhat it does
for i in range(1, 6):Outer loop — runs i from 1 to 5 (5 rows total, since range(1,6) excludes 6).
for j in range(0, i):Inner loop — runs j from 0 up to i-1, so it loops i times for each row.
print("*", end=" ")Prints a star and a space, staying on the same line (end=" " overrides the default newline).
print("")After the inner loop completes, this moves to a new line to start the next row.

Expected Output:

*
* *
* * *
* * * *
* * * * *
Note: Row i prints exactly i stars — this is the key relationship to remember for any triangle-pattern problem.

Making It Dynamic — Taking User Input

Instead of hardcoding range(1, 6), the number of rows can be taken from the user so the pattern size becomes flexible.

rows = int(input("Enter the number of rows"))

for i in range(1, rows + 1):
    for j in range(0, i):
        print("*", end=" ")
    print("")

Explanation of changes

  • input("Enter the number of rows") — prompts the user and returns their input as a string.
  • int(...) — converts that string into an integer, since range() requires integers.
  • range(1, rows + 1) — changed from a hardcoded 6 to rows + 1, so the loop runs exactly rows times (e.g., if rows = 10, it loops i from 1 to 10).

Things to Remember

  • Outer loop = rows, inner loop = stars per row.
  • end=" " in print() keeps output on the same line.
  • A plain print("") (or print()) is the trick used to move to a new line after each row.
  • range(1, i) type inner loops are common for increasing patterns — the inner loop's upper bound is tied to the outer loop's current value (i), not a fixed number.
  • Always convert input() results with int() (or float()) when they'll be used in numeric operations like range().
  • Python Tutor is a great debugging/learning tool for visualizing nested loop execution step by step — especially useful when a loop's logic isn't intuitive yet.

Quick Revision

To print a triangle of stars with n rows:

rows = int(input("Enter the number of rows"))
for i in range(1, rows + 1):      # controls row number / stars in that row
    for j in range(0, i):         # runs i times for row i
        print("*", end=" ")       # stay on same line
    print("")                     # move to next line after row is done
  • Row i → i stars.
  • Inner loop fully completes before outer loop moves to the next i.
  • Use Python Tutor to step through and watch i, j, and the output panel update in real time if the logic feels unclear.
